# RegistrationWarpfield
Scripts/
RegisterImages.py 
Contains recipe used to register images and generate warpmaps or deformation fields.

RegisterLocalizations.py
Script to register localization coordinates (pixel) with the deformation field.

ScatterPlots.py
Generates plots to compare grouundtruth to generated localizations etc.
